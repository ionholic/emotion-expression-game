# 마음 얼굴 연구소

카메라를 보며 열 가지 감정 표정을 연습하거나 현재 얼굴 움직임과 가까운 표정을 5초 동안 읽어 보는 정적 웹 서비스입니다. 얼굴 영상은 브라우저 안에서 MediaPipe Face Landmarker로 처리하며, 사진이나 영상을 저장하지 않습니다.

## 바로 플레이

https://ionholic.github.io/emotion-expression-game/

## 주요 기능

- 기쁨, 슬픔, 화남, 놀람, 무서움, 싫음, 걱정, 부끄러움, 신남, 편안함의 10개 미션
- 5초 동안 얼굴 움직임을 판독하고 가까운 표정과 상위 3개 비율을 알려 주는 `지금 표정 읽기` 모드
- 눈썹·눈·코·입으로 나눈 감정별 표정 가이드
- 시작 화면의 추상 카메라 정렬·감정 분석 그래픽
- 얼굴 부위별 선형 아이콘과 현재 가이드 부위 순환 강조
- 편안한 얼굴과 웃는 얼굴을 함께 사용하는 개인별 미소 특징 범위 보정
- 10개 감정의 닮은 정도를 각각 0~100%로 보여 주는 실시간 분석표
- 모바일에서 카메라를 먼저 보여 주고 상위 3개 분석·전체 10개·표정 가이드를 선택해 펼치는 반응형 구성
- 세로·가로 화면과 노치·홈 인디케이터 안전 영역을 고려한 하단 고정 조작부
- 모바일에서는 카메라 해상도와 분석 빈도를 가볍게 조정하고, 앱 전환·화면 잠금·회전 시 자동 일시정지
- 3초 준비 → 10초 도전 → 5초 최종 분석으로 이어지는 라운드 진행
- 10초 안에 성공하지 못하면 마지막 5초 중 끝부분 2초의 표정을 평균해 최종 판정
- 얼굴을 찾지 못하거나 위치·거리 조건이 맞지 않는 동안 자동으로 멈추는 타이머
- 게임과 5초 판독의 일시정지·계속하기 및 처음으로 이동
- 순간 오인식을 줄이는 점수 평활화와 목표 감정 1위·점수 차·약 0.85초 유지 판정
- 카메라 권한이 없거나 판정이 어려울 때 사용할 수 있는 연습 모드와 건너뛰기
- 카메라 연결 실패 후 현재 화면에서 바로 다시 연결하는 복구 흐름
- 라운드 결과를 충분히 읽은 뒤 직접 다음 표정이나 최종 결과로 이동하는 확인 버튼
- 일시정지·앱 전환·결과 확인 중 얼굴 분석을 쉬어 모바일 발열과 배터리 사용을 줄이는 처리
- 데스크톱·태블릿·모바일 반응형 화면
- 카메라 영상 및 얼굴 분석 결과 비저장

## 실행 방법

카메라와 JavaScript 모듈이 안정적으로 작동하도록 파일을 직접 열기보다 로컬 서버로 실행합니다.

```powershell
cd "D:\OneDrive\Github\Ni-Ti\10_Projects\감정 다이어리\02_아이디어\emotion-expression-game"
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 최초 카메라 시작 시 MediaPipe 라이브러리, WASM 런타임, 얼굴 모델을 인터넷에서 내려받습니다.

모바일에서는 Safari 또는 Chrome으로 위의 공개 주소를 열고 카메라 사용을 허용하면 됩니다. 다른 앱을 보고 돌아오거나 화면 방향을 바꾼 경우 `계속하기`를 눌러 현재 라운드 또는 5초 판독을 이어갈 수 있습니다.

## 배포 시 유의사항

- 실제 웹 주소에서는 HTTPS가 필요합니다. `localhost`와 `127.0.0.1`은 개발용 보안 컨텍스트로 사용할 수 있습니다.
- `@mediapipe/tasks-vision`은 `0.10.35`로 고정되어 있습니다.
- 얼굴 모델과 라이브러리를 완전히 자체 호스팅하려면 `app.js` 상단의 세 URL을 로컬 자산 경로로 변경합니다.
- 카메라 분석 간격은 기기 처리 속도에 따라 자동으로 조정됩니다.
- 이 게임은 사용자의 실제 감정을 진단하지 않습니다. 제시된 감정 표정과 관찰 가능한 얼굴 움직임이 닮았는지만 확인합니다.

## 판정값 조정

`app.js`의 `EMOTIONS` 배열에서 감정별로 다음 값을 조정할 수 있습니다.

- `threshold`: 성공으로 인정할 평균 점수
- `features[].target`: 각 얼굴 움직임이 충분하다고 판단하는 목표값
- `features[].weight`: 감정 점수에서 해당 움직임이 차지하는 비중
- `penalties`: 비슷한 다른 표정과 구분하기 위한 감점 특징

분석표의 퍼센트는 합계가 100%가 되는 확률이 아닙니다. 각 감정 표정과 독립적으로 얼마나 닮았는지를 보여 주는 안내값입니다. 최종 분석에서는 최고 점수가 너무 낮으면 가장 가까운 표정을 참고값으로 안내하고, 1·2위 차이가 작으면 `여러 표정이 함께 보여요`로 안내합니다.

실제 아동 사용자와 시험할 때는 성공률뿐 아니라 실패가 오래 이어지는 감정, 조명, 안경, 카메라 높이, 얼굴 움직임 차이를 함께 기록해 판정값을 조정하는 것이 좋습니다.

전반 점검 결과와 다음 개발 우선순위는 `PROJECT_AUDIT.md`에서 확인할 수 있습니다.
